# 贵州国企招聘监控

自动监控 **贵州国企/事业单位/合同制** 招聘信息，每小时自动推送匹配岗位到 **钉钉**。

## 效果演示

钉钉每天收到类似消息：

```
### 贵州国企招聘监控 2026-05-23

共 5 个符合条件的岗位:

1. 【国企】贵州桥梁建设集团有限责任公司2026年公开招聘公告
   [新] 163贵州网 | https://163gzw.cn/article/91378.html

2. 【国企】遵义市鑫财投资（集团）有限公司...
   163贵州网 | https://163gzw.cn/article/91325.html
...
```

点击链接直接跳转到招聘详情页。

## 一、工作原理

```
163贵州网 ──┐
             ├──→ 粗筛（标题匹配）→ 精筛（详情页分析）→ 钉钉推送
贵州人才博览会 ──┘
```

1. **抓取**：每小时从 163贵州网、贵州人才博览会 获取最新招聘信息
2. **粗筛**：基于标题快速过滤（地点、专业、岗位类型）
3. **精筛**：打开详情页提取学历、经验、职称要求，排除不匹配的
4. **推送**：匹配结果通过钉钉机器人发送

## 二、部署步骤

### 1. Fork 仓库

访问 https://github.com/cymylive/guizhou-job-monitor 点击右上角 **Fork**。

> 也可以直接使用原始仓库，但 Fork 后可以在自己仓库修改 config.json 配置。

### 2. 配置钉钉机器人

1. 打开钉钉，进入目标群
2. 点击群设置 → **智能群助手** → **添加机器人**
3. 选择 **自定义**（通过Webhook接入）
4. 设置机器人名称（如"招聘监控"），安全方式选 **无**
5. 复制 Webhook 地址中的 `access_token=` 后面的部分

```
完整地址: https://oapi.dingtalk.com/robot/send?access_token=这里的一串字符
                                            └───── 复制这段 ────┘
```

### 3. 设置 GitHub Secrets

进入自己 Fork 的仓库，按以下路径操作：

```
Settings → Secrets and variables → Actions → New repository secret
```

| 名称 | 值 |
|------|-----|
| `DINGTALK_TOKEN` | 上一步复制的 access_token |

### 4. 手动运行测试

```
Actions → 贵州国企招聘监控 → Run workflow
```

等待 1-2 分钟后查看钉钉是否收到消息。也可以点进 workflow 查看运行日志。

## 三、自定义匹配规则

所有匹配规则都写在仓库根目录的 **`config.json`** 中，直接编辑即可，无需修改 Python 代码。

编辑后提交：

```bash
git add config.json
git commit -m "修改匹配规则"
git push
```

GitHub Actions 下次运行时自动使用新配置。

### 修改求职者信息

```json
{
  "求职者信息": {
    "学历": "本科",
    "专业": "经济与金融",
    "工作经验年": 1,
    "期望城市": ["贵阳", "安顺", "平坝", "遵义"],
    "非党员": true
  }
}
```

- `期望城市` — 岗位工作地点包含这些关键词才推送
- `工作经验年` — 用于判断是否超出要求

### 修改包含条件

```json
{
  "包含条件": {
    "岗位类型": ["国企", "事业编", "合同制", "见习"],
    "专业关键词": [
      "经济", "金融", "管理", "财务", "会计",
      "审计", "不限专业", "专业不限"
    ],
    "学历关键词": ["本科及以上", "本科"],
    "特殊岗位": ["见习", "管培", "应届"]
  }
}
```

- 想投递 **计算机** 岗位 → 在 `专业关键词` 里加上 `"计算机"`
- 不想看 **见习** 岗位 → 从 `特殊岗位` 里去掉 `"见习"`

### 修改排除条件

```json
{
  "排除条件": {
    "经验要求": ["2年以上", "3年以上", "5年以上"],
    "硬性要求": ["中共党员", "高级职称", "注册会计师"],
    "特定专业": ["土木工程", "安全工程"],
    "岗位排除": ["工程师", "技术员", "医师", "总监", "经理岗"]
  }
}
```

- 岗位标题/详情包含任意排除关键词 → **不推送**
- 如果你想接受 **中共党员** 要求的岗位 → 从 `硬性要求` 里去掉 `"中共党员"`
- 添加自定义排除 → 直接在对应数组里加关键词

### 修改推送设置

```json
{
  "推送设置": {
    "每小时推送": true,
    "最多推送岗位数": 50,
    "显示详情": true
  }
}
```

- `每小时推送` — `true` 每小时推送一次，`false` 每天推送一次
- `最多推送岗位数` — 避免消息过长

### 修改抓取来源

```json
{
  "抓取来源": {
    "163贵州网": {
      "启用": true,
      "页面数": 4
    },
    "贵州人才博览会": {
      "启用": true,
      "学历过滤": "本科",
      "企业性质": "国有企业"
    }
  }
}
```

- `页面数` — 数值越大抓取越多（4页约120条）
- `启用` — `false` 关闭该来源

## 四、FAQ

**Q: 需要本地电脑吗？**
不需要。全部在 GitHub 云端运行。

**Q: 运行频率？**
每小时一次（UTC 整点 = 北京时间 8:00/9:00...）。也支持手动触发。

**Q: 可以同时推送到多个钉钉群吗？**
可以。Fork 多个仓库，每个配置不同的 `DINGTALK_TOKEN`。

**Q: 匹配不准怎么办？**
编辑 `config.json` 调整关键词即可，无需懂代码。

**Q: 费用？**
完全免费。GitHub Actions 免费额度足够。

**Q: 是否包含不需要笔试的岗位？**
脚本会根据岗位标题和详情匹配，不会区分是否需要笔试。建议报名前自行查看公告确认。
